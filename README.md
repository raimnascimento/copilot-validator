# Github Copilot 🤖 Validador de Cartão de Crédito

Este projeto foi desenvolvido como parte do **Bootcamp Microsoft AI for Tech - GitHub Copilot**, ministrado por **Pablo Lopes**.

Durante o bootcamp, aprendi sobre os princípios da inteligência generativa, conceitos importantes relacionados ao tema, a origem do GitHub Copilot e, o mais importante, como usar essa ferramenta poderosa para auxiliar no desenvolvimento de código.

O código deste projeto foi criado totalmente com o auxílio do GitHub Copilot, com o intuito de aprender na prática, demonstrando como a inteligência artificial pode ser utilizada para aumentar a produtividade e a qualidade do código.

Este projeto em JavaScript tem como objetivo validar números de cartão de crédito e identificar a bandeira do cartão (Visa, Mastercard, etc.). O código utiliza o algoritmo de Luhn para verificar a validade do número e expressões regulares para identificar a bandeira.

## Funcionalidades 💳

- **Validação do número do cartão:** Verifica se um número de cartão de crédito é válido usando o algoritmo de Luhn.
- **Identificação da bandeira:** Identifica a bandeira do cartão de crédito (Visa, Mastercard, American Express, etc.) com base no número do cartão.
